Blocaïne is a software platform designed for the automation of industrial processes.
It includes two main components:
•A Block Editor, which allows you to create programs by assembling functional blocks.
•An Interpreter, which executes the programs created with the Block Editor, thus controlling the industrial equipment via remote inputs/outputs.

Blocaïne est une plateforme logicielle conçue pour l'automatisation des procédés industriels.
Elle comprend deux composants principaux :
•Un Éditeur de blocs, qui permet de créer des programmes en assemblant des blocs fonctionnels.
•Un Exécuteur , qui interprète les programmes créés avec l’Éditeur de blocs, pilotant ainsi l’équipement industriel via des entrées/sorties déportées.
