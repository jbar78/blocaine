Blocaïne is a software platform designed for the automation of industrial processes.
 • A Block Editor, allows to create programs by assembling functional blocks.
 • An Interpreter, executes the programs created with the Block Editor, thus controlling the industrial equipment via remote I/O.

Blocaïne est une plateforme logicielle conçue pour l'automatisation des procédés industriels.
 • Un Éditeur de blocs permet de créer des programmes en assemblant des blocs fonctionnels.
 • Un Exécuteur interprète les programmes créés avec l’Éditeur de blocs, pilotant ainsi l’équipement industriel via des entrées/sorties déportées.
