2Fonction

Le bloc <OPC_server> permet de configurer un serveur OPC UA et donc de créer les objets « server » et « node », puis dans un second temps de démarrer et arrêter le serveur.

Se reporter à la documentation du module Python « opcua » pour plus de détails.

3Les entrées

  • •« port» : C’est le numéro de port qu’utilisera le serveur pour exposer les nœuds et variables OPC UA. Le port par défaut est 4840 (int) 

  • •« Start » : Permet de démarrer le serveur, le démarrage du serveur doit être activé que lorsque tous les nœuds et variables OPC ont été configurés à l’aide des blocs  <OPC_node> et <OPC_var>. La valeur par défaut est False 

  • •« Stop » : Permet d’arrêter le serveur. La valeur par défaut est False 

  • •« Status » : 0=ok, -1=Exception Python, -2=Serveur non configuré et en Stop, 1= serveur en démarrage, 2= serveur configuré, 3=serveur à l’arrêt 

4Les sorties

  • •« Server » : Cet objet « opcau » est créé si sa valeur précédente est None (donc à la première exécution du bloc), il doit être utilisé par les autres blocs OPC tel que <OPC_node> et <OPC_var>. La valeur par défaut est None    

  • •« Node » : Cet objet « opcau » est créé en même temps que la sortie « Server », C’est le nœud principal à partir duquel vous pourrez créer d’autres nœuds ou variables OPC en utilisant respectivement <OPC_node> et <OPC_var>. La valeur par défaut est None 

  • •« Started » : indique si le serveur est démarré 

5Types

les sorties « Server » et « Node » sont de type définis par le module Python « opcua »
