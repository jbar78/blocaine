1Interface graphique

 

2Fonction

Le bloc <OPC_node> permet de configurer (créer) un noeud OPC UA et donc de créer un objet « node ».

 

Se reporter à la documentation du module Python « opcua » pour plus de détails.

3Les entrées

  • •« Server» : Cet objet provient du bloc <OPC_server>. La valeur par défaut est None 

  • •« Node » : C’est le nœud parent, cet objet provient soit du bloc <OPC_server>, soit d’un autre bloc <OPC_node>. La valeur par défaut est None 

  • •« Name » : C’est le nom du nœud créé par ce bloc. La valeur par défaut est ‘node’ (str) 

4Les sorties

  • •« Node » : cette objet « opcau » est créé si sa valeur précédente est None (donc à la première exécution du bloc), il peut être utilisé par le bloc <OPC_var> ou un autres blocs <OPC_node>. La valeur par défaut est None    

  • •« Status » : 0=ok, -1=Exception Python, -2=Serveur non configuré, -3= nœud parent non configuré 

5Types

les sorties « Server » et « Node » sont de type définis par le module Python « opcua »
