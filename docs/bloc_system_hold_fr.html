2Fonction

Le bloc <hold> assure la fonction de maintien. Si l’entrée « gate » est True, alors la sortie « out » est identique à l’entrée « in », sinon la sortie « out » reste inchangée.  

Notez que la chaîne de blocs en amont de l’entrée « in » n’est évaluée que si nécessaire, donc seulement si la « gate » est à True.

3Les entrées

  • •« gate » : La valeur par défaut est False (type bool),  

  • •« in » : La valeur par défaut est 0 (type int) 

4La sortie

  • •« out » : est la mémoire, c’est une variable mémorisée qui peut être initialiser, ce qui explique la couleur de fond vert pomme 

5Types

Le type de l’entrée « gate » est bool.

Le type de l’entrée « in » peut être quelconque, la sortie « out » sera du même type.
