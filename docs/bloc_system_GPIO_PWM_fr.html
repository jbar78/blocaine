2Fonction

Le bloc <GPIO_PWM> permet de configurer une des pines du GPIO d’un Raspberry pi en sortie MLI (Modulation Largeur Impulsion) et d’affecter sa valeur, sauf si« close » est vrai.

Se reporter à la documentation du module gpiozero pour plus de détails.

3Les entrées

  • •« close » : libère la pine de toute configuration si vrai. La valeur par défaut est faux 

  • •« pin » : c’est le numéro BCM de la pine du GPIO. La valeur par défaut est 0 (type int) 

  • • « value » : c’est l’état désiré de la sortie MLI, entre 0.0 et 1.0  La valeur par défaut est 0 (type float)  

4Les sorties

  • •« status » : -1 si la pine n’est pas configurée,  0 si ok,  3 si configurée en « PWMLED » 

  • •« obj » : c’est l’objet « PWMLED » (variable mémorisée) 

5Usage

Lorsqu’un Raspberry pi est utilisé comme cible, ce bloc permet l’utiliser une pine du GPIO comme sortie MLI. Notez que la fonction PWM est native sur certaines pines.
