2Function

The <div> block is equivalent to the “/” operator in Python; it allows you to:

  • •Divide « a » by « b » 

Note that the result is always a float, even if both inputs are of type int.

Refer to the Python documentation for more details.

3Inputs

  • •« a » : The default value is 0.0 (float type) 

  • •« b » : The default value is 1.0 (float type) 

4Output

  • •« out » : Its type depends on the type of the inputs 

5Types

If one of the inputs is of type int or float, the other input must also be one of these two types.
