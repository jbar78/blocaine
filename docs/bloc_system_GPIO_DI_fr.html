2Fonction

Le bloc <GPIO_DI> permet de configurer une des pines du GPIO d’un Raspberry pi en entrée digitale et de lire sa valeur, sauf si« close » est vrai.

Se reporter à la documentation du module gpiozero pour plus de détails.

3Les entrées

  • •« close » : libère la pine de toute configuration si vrai. La valeur par défaut est faux 

  • •« pin » : c’est le numéro BCM de la pine du GPIO. La valeur par défaut est 0 (type int) 

4Les sorties

  • •« value » : c’est l’état actuel de l’entré digitale, True si état haut, False si état bas. 

  • •« status » : -1 si la pine n’est pas configurée,  0 si ok,  1 si configurée en « Button » 

  • •« obj » : c’est l’objet « Button » 

5Usage

Lorsqu’un Raspberry pi est utilisé comme cible, ce bloc permet l’utiliser une pine du GPIO comme entrée digitale. Notez que par défaut un résistance de pull-up tire l’entrée vers l’état haut, il faudra donc soit laisser l’entrée en l’air, ce qui donnera un état haut (True), soit mettre l’entée à la masse, ce qui donnera un état bas (False)
