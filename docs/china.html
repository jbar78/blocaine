布洛凯恩 (Blocaine) 是一个专用于
工业流程自动化的软件平台。


  • 块编辑器 允许通过组装功能块来创建程序。
  • 解释器 执行通过 块编辑器 创建的程序，从而通过远程 I/O 控制工业设备。


演示...

功能特性
  • " 热重载* "：程序的新版本可以在不停止安装的情况下加载
  • 以链式功能块形式进行图形化编程
  • 每个变量原生具有有效位
  • 布洛凯恩基于 Python：
    • 功能块可以用 Python 编写
    • 变量的动态类型
  • 调试：
    • 变量的实时可视化
    • 所有变量都可以强制设置
  • 块的执行顺序自动生成
  • 布局自动排列
  • 一个 Web 服务器显示目标计算机上当前运行任务的状态
  • 一个 OPC UA 服务器提供与潜在 HMI/SCADA 系统的接口
  • 布洛凯恩是多平台的（Windows、Linux、macOS...）
  • 布洛凯恩是免版税且“开源”的
优势
  • 布洛凯恩是一款 " KISS* " 软件
  • 得益于永恒标准（PC、以太网、Python），最大限度减少过时风险
  • 无需许可证
项目状态
  • 布洛凯恩处于“功能原型”阶段（Alpha 版本）
  • 布洛凯恩可从 github.com 下载（见 安装和评估流程）
评估
由于可下载版本已配置好，因此 布洛凯恩的评估 变得非常简单：
  • 块编辑器 和 解释器 在同一台计算机上运行，因此无需网络配置
  • 多个功能被禁用（OPC、GPIO、Modbus/TCP），因此无需安装任何特定的 Python 模块

系统块：
  • add 加法
  • and 逻辑与

  • edge 上升沿和/或下降沿检测
  • filter_FO 一阶滤波器
  • geti 返回元素 [n]
  • GPIO_DI 读取 GPIO 数字输入
  • GPIO_DO 写入 GPIO 数字输出
  • GPIO_PWM 写入 GPIO PWM 输出
  • information 返回变量信息
  • input 块输入
  • input_output 访问另一个进程的输出
  • insert 将元素插入列表
  • integrator 基于时间的积分器
  • len 返回元素数量
  • limit 上下限
  • memory 存储器（RS 触发器）
  • minmax 最小值和最大值
  • modbus_conn ModBus/TCP 连接
  • modbus_read ModBus/TCP 输入读取
  • modbus_write ModBus/TCP 输出分配
  • mult 乘法
  • not 逻辑非
  • OPC_node 创建 OPC UA 节点
  • OPC_read 获取 OPC UA 变量
  • OPC_server 配置 OPC UA 服务器
  • OPC_var 创建 OPC UA 变量
  • OPC_write 设置 OPC UA 变量
  • or 逻辑或
  • output 块输出
  • pop 从列表中移除元素
  • previous 存储的变量
  • puti 在列表中设置一个元素
  • range 循环迭代
  • select 选择（if then else）
  • sub 减法
  • time 系统时钟读取
  • type 类型转换
  • validRead 有效位读取
  • validWrite 有效位写入
