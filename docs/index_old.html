Blocaïne est une plateforme logicielle dédiée à
l'automatisation des procédés industriels


  • L'Éditeur de bloc permet de créer des programmes en assemblant des blocs fonctionnels.
  • L'Exécuteur, exécute les programmes créés avec l’Éditeur de bloc, pilotant ainsi l’équipement industriel via des entrées/sorties déportées.


voir aussi le Tuto d'installation (en moins de 3 minutes)
Caractéristiques
  • « Chargement à Chaud* » : une nouvelle version d'un programme peut être chargée sans arrêter l'installation
  • Programmation graphique sous forme de blocs fonctionnels chaînés
  • Chaque variable possède nativement un bit de validité
  • Blocaine étant basée sur Python:
    • Ecriture possible de blocs fonctionnels en Python
    • Typage dynamique des variables
  • Débogage:
    • Visualisation en temps réel des variables
    • Toutes les variables sont forçables
  • L’ordre d’exécution des blocs est généré automatiquement
  • La mise en page est automatique
  • Un serveur web affiche l'état des tâches en cours d'exécution dans la machine cible
  • Un serveur OPC UA fait l'interface avec un éventuel IHM/SCADA
  • Blocaïne est multiplaforme (Windows, Linux, macOS...)
  • Blocaïne est libre de droits et en sources ouvertes
Avantages
  • Philosophie « KISS » (Keep It Simple, Stupid)
  • Low cost
  • Minimise l'obsolesence grace à des standards pérennes (PC, Ethernet, Python)
  • Pas de licence
Limitations
  • Ressources CPU: Blocaïne n'est pas adapté au gros projets demandant beaucoup de temps CPU, le temps d'exécution d'un bloc est de l'ordre de 2µs sur Raspberry pi 5, soit un maximum d'un demi-million de blocs par seconde
  • Temps réel: Blocaïne n'étant pas basé sur un system temps réel "dur", il faut accepter une certaine latence qui reste cependant inférieur à 1µs sur Raspberry pi 5
  • Bibliothéques: comme le projet est récent vous risquez de ne pas trouver tous les blocs "system" que vous souhaitez (voir la liste des blocs disponibles ci-dessous)
Avancement du projet
  • Blocaïne est au stade de « Prototype Fonctionnel » (version Alpha)
  • Blocaïne est téléchargable sur github.com (voir précédure d'installation et d'évaluation)
Evaluation
La durée d’installation pour évaluation est inférieur à 3 minutes, puisque la version téléchargeable est configurée pour que:
  • l'Éditeur de bloc et l'Exécuteur s'exécutent sur le même PC, ce qui élimine toute configuration réseau
  • Certaines fonctionnalités sont déactivées (OPC, GPIO, MudBus/TCP), ce qui élimine toute installation de modules Python spécifiques
