2Fonction

Le bloc <writebit> écrire un bit dans un entier :

3Les entrées

  • •« in » : c’est l’entier dont on change un bit. La valeur par défaut est 0 (type int) 

  • •« bit# » : c’est le numéro du bit, de 0 à 63 (ou plus). La valeur par défaut est 0 (type int). Étant donné qu’en python un int n’a pas de valeur limite, « bit# » peut être supérieur à 63.  

  • •bit_value ; c’est la valeur (True/False) du bit « bit# » qui est écrit la sortie    

4La sortie

  • •« out » : la valeur de la sortie est identique à l’entée « in », sauf que le bit « bit# » y est changé par l’entrée « bit_value »  

5Types

Les entrées « in » et « bit# » sont de type : int

l’entrée « bit_valuet » est de type : bool

La sortie out est de type : int
