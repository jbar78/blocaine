1Interface graphique

 

2Fonction

Le bloc <OPC_write> permet de donner une valeur à une variable OPC UA.

 

Se reporter à la documentation du module Python « opcua » pour plus de détails.

3Les entrées

  • •« Var » : C’est un objet « opcua » représentant une variable OPC AU, cet objet provient d’un bloc <OPC_var>. La valeur par défaut est None 

  • •« Value » : C’est la valeur que prendra la variable OPC UA un fois le bloc exécuté. La valeur par défaut est 0 (int) 

4La sortie

  • •« Status » : 0=ok, -1=Exception Python, -2=variable OPC UA non configuré 

5Types

L’entrée « Var » est de type définis par le module Python « opcua », l’entrée « Value » est du même type que la variable OPC UA.
