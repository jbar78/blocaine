2Fonction

Le bloc <append> il permet d’ajouter un élément à la fin d’une list, il directement référence à la fonctions Python: .append()

Se reporter à la documentation Python pour plus de détails.

3Les entrées

  • •« list » : variable à laquelle on souhaite ajouter un élément, la valeur par défaut est une list vide. 

  • •« elem » : élément à ajouter (en fin) à l’entrée « list », la valeur par défaut est 0 int 

  • •« list » : est la liste contenant le nouvel élément 

4La sortie

  • •« list » :  (du type défini par entrée « type ») 

5Types

L’entrée et la sort « list » sont de type list, l’entrée « elem » peut être de n’importe quel type

6Usage

Comme « list » sortie = « list » entrée ‘+’ « elem », après l’exécution du bloc les 2 listes sont identiques
